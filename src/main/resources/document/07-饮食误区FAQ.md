# 07-饮食误区FAQ

高频饮食误区速查。看到这些说法先打个问号，再对照科学证据。

## 关于减肥的误区

- 误区：不吃主食/断碳水能长期减肥。事实：短期掉秤多为水分，长期低代谢易暴食，减脂应粗细搭配、控制总量而非断碳。
- 误区：过午不食、一天只吃一顿更减脂。事实：总热量不变时，进食频率本身不影响减脂；但长时间空腹易低血糖和报复性进食。
- 误区：喝苹果醋、吃酵素能躺着瘦。事实：苹果醋对血糖有轻微帮助，但无直接燃脂证据；酵素（酶）进胃就被分解，靠它减肥不靠谱。
- 误区：吃"负卡路里"食物（芹菜等）能越吃越瘦。事实：没有真正的负卡路里食物，只是热量很低，仍需控制总摄入。
- 误区：出汗多=瘦得多。事实：出汗排的是水，运动后体重下降主要是水分，补水就回来；减脂看的是热量缺口。
- 误区：局部减脂（瘦肚子、瘦腿）存在。事实：脂肪是全身一起动员消耗的，不存在"练哪瘦哪"，只能全身减脂+局部塑形。

## 关于"养生吃法"的误区

- 误区：喝粥养胃，顿顿喝粥。事实：长期只喝粥胃功能会退化，血糖也易升高；养胃讲究规律饮食、细嚼慢咽，不是只喝粥。
- 误区：汤越浓越补，骨头汤补钙、鸡汤补蛋白。事实：浓汤主要是脂肪、盐和嘌呤，钙/蛋白含量很低，营养在肉里不在汤里。
- 误区：趁热吃对胃好。事实：超过 65℃ 的热饮热食被列为 2A 类致癌物（食管癌风险），"趁热吃"是伤害不是养生。
- 误区：蜂蜜水润肠通便、比糖健康。事实：蜂蜜主要成分就是果糖和葡萄糖，通便作用因人而异（果糖不耐受者"通便"其实是腹泻），热量与糖无异。

## 关于食物的误区

- 误区：土鸡蛋比普通鸡蛋更营养。事实：两者蛋白质、维生素差距很小，土鸡蛋脂肪和胆固醇略高，口感差异大于营养差异。
- 误区：果汁等于水果。事实：榨汁去掉了纤维、浓缩了糖，一杯橙汁的糖约等于 2~3 个橙子，饱腹感却差得多。
- 误区：晚上吃水果/主食会胖。事实：只要总热量不超，什么时候吃差别不大；真正致胖的是全天总盈余。
- 误区：脱脂/低脂食品一定更健康。事实：很多"低脂"产品为口感加了更多糖，看配料表和总热量，别只看"低脂"标签。
- 误区：有机食品营养更高。事实：有机主要减少农残暴露，营养密度证据并不一致，预算有限时先保证蔬果总量更重要。

## 关于代餐与补剂的误区

- 误区：代餐奶昔可以长期当饭。事实：代餐适合短期体重管理辅助，长期单一代餐易缺微量营养素，且不改变饮食习惯容易反弹。
- 误区：左旋肉碱躺着减肥。事实：左旋肉碱只是脂肪转运的"搬运工"，不运动时基本没用，运动时人体自身也够用，靠它减肥无依据。
- 误区：排毒清肠能减肥养生。事实：人体有肝肾负责代谢"排毒"，不需要泻药式清肠，频繁清肠反而破坏肠道菌群和电解质平衡。
- 误区：酵素、青汁能替代蔬菜。事实：青汁本质是干燥蔬菜粉，膳食纤维有部分保留，但绝不能替代新鲜蔬果的完整营养。
