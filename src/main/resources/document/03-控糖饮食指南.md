# 03-控糖饮食指南

控糖（糖尿病 / 糖前期 / 妊娠期血糖管理）的核心是「平稳血糖」，不是一刀切戒糖。会吃主食，比完全不吃主食更重要。

## 看懂 GI 和 GL

- GI（升糖指数）：反映食物升高血糖的速度。GI ≤ 55 为低 GI，56~69 中 GI，≥ 70 高 GI。
- GL（血糖负荷）= GI × 每份食物碳水含量 / 100，更贴近"吃了多少"。比如西瓜 GI 高（72）但 GL 低（一片约 5），少量吃可以。
- 结论：控糖不只看"甜不甜"，白米饭 GI 83 比不少水果都高，甜度不能作为判断依据。

## 主食怎么吃

- 粗细搭配：把精白米面的 1/3~1/2 换成燕麦、糙米、荞麦、全麦、杂豆，餐后血糖更平缓。
- 控制份量：每餐主食（熟重）约一拳头（相当于生米 50~75 g），分到三餐，不要一餐吃很多、一餐不吃。
- 进餐顺序：先蔬菜后肉蛋最后主食，实验证实可显著降低餐后血糖峰值。
- 加醋/放凉：米饭放凉产生抗性淀粉、佐餐加醋，都能略微降低餐后血糖反应。

## 水果和饮料

- 水果：优先低 GI 水果（苹果、梨、草莓、柚子、樱桃），整果优于果汁，果汁去掉了纤维、升糖接近糖水。
- 饮料：含糖饮料、蜂蜜水、鲜榨果汁都是"液态糖"，尽量避免；无糖饮料（代糖）可偶尔饮用，但不建议当水喝。
- 警惕"隐形糖"：红烧肉、糖醋菜、甜面酱、奶茶"三分糖"都可能让你的控糖前功尽弃。

## 常见问题

- 问：糖尿病人能吃水果吗？答：血糖控制平稳时（空腹 <7、餐后 2h <10 左右）可以吃，放在两餐之间，每次一小份（约一个拳头大小或 150~200 g），并从主食里扣除相应碳水。
- 问：吃粗粮就能随便多吃吗？答：不能。粗粮只是升糖慢，热量和碳水仍在，GL 一样要控制。
- 问：无糖食品可以放开吃吗？答：很多"无糖饼干"用淀粉 + 油脂做成，升糖和热量都不低，看配料表第一位的还是小麦粉。
- 问：柚子能降血糖吗？答：柚子本身不降糖，只是低 GI 负担小，别把它当药吃。
