# 05-痛风高尿酸饮食指南

痛风是尿酸盐结晶沉积导致的关节炎，饮食管理分「急性发作期」和「缓解期」两套标准，很多人的误区在于"不管发不发作都严格忌口"或"不发作就乱吃"。

## 嘌呤三档速查

- 低嘌呤（< 50 mg/100 g，可常吃）：绝大多数蔬菜、低脂奶、鸡蛋、大米白面、薯类、水果。
- 中嘌呤（50~150 mg/100 g，缓解期适量、急性期少吃）：多数肉类、禽类、鱼虾蟹贝、豆类及豆制品、香菇等菌菇、芦笋。
- 高嘌呤（> 150 mg/100 g，尽量不吃）：动物内脏、浓肉汤火锅汤、沙丁鱼凤尾鱼带鱼等部分海鱼、牡蛎扇贝、啤酒。

## 急性发作期 vs 缓解期

- 急性期：几乎完全回避高嘌呤食物，严格限酒，大量喝水（每日 2000 ml 以上）促进尿酸排出；豆制品和蔬菜不必全戒，近年证据显示植物性嘌呤对血尿酸影响远小于动物性嘌呤。
- 缓解期：可恢复中嘌呤食物但要限量，红肉每天不超过 100 g，海产每周 2~3 次且每次少量，仍避免内脏和浓汤。

## 比忌口更重要的三件事

- 控体重：超重/肥胖是高尿酸独立危险因素，减重本身就能降尿酸，但别节食过快（脂肪快速分解会产生酮体，反而抑制尿酸排出）。
- 限酒与果糖：啤酒和白酒都升尿酸，酒精是头号敌人；含糖饮料里的果糖会促进尿酸生成，"痛风不能喝啤酒，但可以喝果汁"是常见误区。
- 足量饮水：每日饮水 2000 ml 以上（心肾功能正常前提下），尿液冲刷是排出尿酸最主要途径。

## 常见问题

- 问：痛风能吃豆制品吗？答：可以适量吃。煮黄豆嘌呤中等，但豆腐豆浆经加工嘌呤已大幅流失，且植物嘌呤升尿酸作用弱，不用谈豆色变。
- 问：痛风能喝牛奶吗？答：能，低脂奶还有轻度促尿酸排泄作用，是推荐饮品。
- 问：吃维生素 C 能降尿酸吗？答：大剂量维 C（500 mg/天以上）有轻度促尿酸排泄作用，但效果有限，不能替代降尿酸药。
- 问：尿酸高但没有症状，需要管饮食吗？答：需要。无症状高尿酸血症同样建议控制饮食、限酒、减重，但无需像急性期那样草木皆兵。
- 问：痛风发作时能热敷吗？答：这是误区。急性期应冷敷并抬高患肢，热敷会加重炎症肿胀。
