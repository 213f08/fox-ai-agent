# 06-维生素矿物质指南

微量营养素"量小作用大"，缺了会出各种症状，但乱补反而可能中毒或干扰吸收。按需吃、优先从食物补。

## 容易缺的几种维生素

- 维生素 D：国人普遍缺乏。来源：晒太阳（每天 15~30 分钟、露出手臂小腿）、深海鱼、蛋黄、强化奶。食物来源极少，必要时查血后补充剂补。
- 维生素 B12：几乎只存在于动物性食物（肉、蛋、奶、鱼）。长期纯素人群必须额外补充，否则可能贫血、神经损伤。
- 叶酸（B9）：深绿叶菜、豆类、柑橘。备孕和孕早期需补充剂补足 400~800 μg/天，预防胎儿神经管畸形。
- 维生素 C：新鲜蔬果即可满足，辣椒、猕猴桃、柑橘、番茄含量高。维 C 是水溶性的，每天多余的部分随尿排出，过量（>2 g/天）可能腹泻、肾结石。

## 矿物质来源与误区

- 钙：奶制品、豆腐、芝麻酱、深绿叶菜。喝骨头汤补钙是误区——骨头汤钙含量约 10 mg/100 ml，一碗远不如一杯奶（约 120 mg），且汤里主要是脂肪和嘌呤。
- 铁：分血红素铁（红肉、动物血、肝脏，吸收好）和非血红素铁（菠菜、豆类、红枣，吸收差）。植物铁搭配维 C 同食可提高吸收；浓茶、咖啡会抑制铁吸收，饭后别立刻喝。
- 锌：生蚝、贝类、红肉、坚果。缺锌影响味觉和免疫。
- 钾：香蕉、土豆、豆类、紫菜。肾功能不全、服保钾利尿剂者慎补。
- 碘：海带、紫菜、加碘盐。甲状腺疾病（甲亢等）补碘需遵医嘱。

## 常见问题

- 问：缺铁就吃红枣菠菜可以吗？答：红枣菠菜是植物性铁且含量有限，中重度缺铁性贫血建议红肉动物血 + 铁剂，靠红枣补铁效率太低。
- 问：维生素能随餐一起吃吗？答：脂溶性维生素（A/D/E/K）随含脂肪的餐吃吸收更好；钙和铁最好错开（同服互相干扰吸收），铁与维 C 同服。
- 问：补钙会导致肾结石吗？答：适量补钙（膳食钙）反而降低草酸钙结石风险；肾结石病史者补钙剂型与剂量需遵医嘱。
- 问：复合维生素能替代蔬菜水果吗？答：不能。植物化学物（多酚、膳食纤维等）是药片给不了的，补剂是"查漏补缺"，不是替代品。
- 问：吃得多就一定不缺微量元素吗？答：不一定，精加工饮食（白米白面+少蔬果）热量过剩但微量营养素常常不足，这正是"隐性饥饿"。
